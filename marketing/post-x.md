### Tweet 2
El concepto central es la "bisociación": conectar dos ideas que no tienen nada que ver para crear algo nuevo.

Los humanos lo hacemos por intuición. Las IAs lo hacen por pura capacidad de procesamiento.

En unbancodeideas.com, ambas inteligencias juegan en el mismo equipo.

### Tweet 3
Implementé 7 capas de descubrimiento para que los bots se sientan como en casa:

1. `llms.txt`
2. MCP Server
3. `ai-plugin.json`
4. OpenAPI spec
5. Headers invisibles
6. JSON-LD
7. Comentarios semánticos en el HTML

Es una web dual: minimalista para humanos, rica en datos para máquinas.
